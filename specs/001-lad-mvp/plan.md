# Plan 001 — как строим «Лад»

## Стек
- Статика: `index.html` + `css/style.css` + ES-модули в `js/`. Без сборки, без npm — залил на GitHub, и оно работает.
- Хостинг: GitHub Pages (HTTPS нужен для микрофона и установки на iPhone).
- PWA: `manifest.webmanifest`, `sw.js` (офлайн-кэш), иконки 180/192/512 px.
- Данные: `localStorage` (ключ `lad.v1`): свои песни, избранное, просмотры, настройки. Демо-песни лежат в коде и не удаляются (их можно скрыть).

## Структура
```
index.html               оболочка, нижнее меню, контейнер страниц
css/style.css            тёмная/светлая тема, анимации
js/app.js                роутер (#/, #/song/id, #/artist/имя, #/add, #/edit/id), экраны
js/store.js              чтение/запись localStorage, экспорт/импорт
js/chords.js             распознавание аккордов, транспонирование
js/parser.js             текст «аккорды над словами» → строки с сегментами
js/diagrams.js           аппликатуры (открытые + баррэ E/A-формы) → SVG
js/voice.js              распознавание речи и поиск строки
js/demo-songs.js         народные песни (общественное достояние)
manifest.webmanifest, sw.js, icons/
```

## Ключевые решения
- **Выравнивание аккордов на узком экране:** строку режем на сегменты «аккорд + кусок текста» (inline-block). Сегменты внутри одного слова склеиваются, чтобы слово не рвалось. Так текст переносится естественно, а аккорд не уезжает от своего слога.
- **Транспонирование:** разбор аккорда на корень + «хвост» + бас (D/F#). Русское H = B (си). Диезы или бемоли — по исходной тональности песни.
- **Схемы:** словарь открытых аккордов + генерация баррэ от формы Ми (6-я струна) и Ля (5-я струна) — выбираем ту, что ниже по грифу. Итог — SVG.
- **Голос:** Web Speech API (`ru-RU`, промежуточные результаты, автоперезапуск). Последние ~6 услышанных слов сравниваем со словами песни (нечёткое совпадение: начало слова / одна опечатка), рядом с текущей строкой — с бонусом. Переход, если совпало ≥2 слов. Пока включён голос или автопрокрутка — экран не гаснет (Wake Lock).
- **Анимации:** View Transitions API между экранами (в старых браузерах — CSS fade/slide), каскадное появление списка, «пружинный» поп-ап схемы, свечение активной строки. Учитываем `prefers-reduced-motion`.

- Без микрофона всё работает — автопрокрутка независима от голоса ✅
- Без фреймворков ✅

## Риски
- iOS: распознавание речи в режиме «На экран Домой» на некоторых версиях iOS не запускается → показываем подсказку «открой в Safari».
- localStorage на iPhone может очиститься, если сайт не на экране Домой → кнопка «Экспорт».
