# Лад — аккорды

Веб-приложение с песнями и аккордами: рейтинг, схемы аккордов, смена тональности, автопрокрутка и текст, который едет за твоим голосом.

## Как выложить на GitHub Pages (5 минут)
1. Зайди на github.com → **New repository** → имя, например, `lad` → Public → Create.
2. На странице репозитория: **Add file → Upload files**, перетащи **всё содержимое** этой папки (не саму папку): `index.html`, `css/`, `js/`, `icons/`, `manifest.webmanifest`, `sw.js`. → **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. Через 1–2 минуты сайт будет по адресу `https://ТВОЙ_НИК.github.io/lad/`.

## Как поставить на iPhone
Открой ссылку в **Safari** → кнопка «Поделиться» → **На экран «Домой»**.

## Голос
Кнопка 🎤 на странице песни. Нужны HTTPS (GitHub Pages даёт), интернет и разрешение на микрофон.
Если в иконке с экрана «Домой» микрофон не включается — открой сайт прямо в Safari: на некоторых версиях iOS распознавание речи там работает надёжнее.
Совет: тапни по строке, с которой начинаешь петь, — подсветка начнёт отсюда.

## Как добавлять песни
«Добавить» → вставь текст: строка аккордов, под ней строка слов. Формат `[Am]слово` тоже понимается.
Песни хранятся в памяти браузера — время от времени жми «Ещё → Скачать копию».

## Обновление
Поменял файлы → загрузи их заново в GitHub. В `sw.js` подними `VERSION` (например, `lad-v2`), чтобы телефон точно подтянул новую версию.

## Проверки
`node tests/core.test.mjs` — аккорды, транспонирование, парсер, схемы, поиск строки по голосу.
